3. 원고 입력

📄
원고 파일을 끌어다 놓거나 클릭해서 선택하세요
HWPX · DOCX · PDF · TXT — 여러 편 동시 선택 가능, 논문당 10MB 이하 (HWP 구형은 HWPX/PDF로 변환 후 사용)
원고 파일을 만들지 않고 몇 건만 빠르게 확인할 때 쓰세요. 서버에 원고 파일이 보관되지 않습니다. 본문이 없으므로 ‘본문 인용 ↔ 목록 대조’는 자동으로 제외됩니다.
폴더 안의 지원 형식 파일을 모두 처리하고, 결과를 같은 폴더의 참고문헌_정리결과 하위 폴더에 파일별 DOCX + 종합리포트로 저장합니다.

설정 — AI 엔진
console.anthropic.com에서 발급. 키는 이 컴퓨터의 app/config.json에만 저장됩니다.
기본값 claude-opus-5(정확도 우선). 비용을 줄이려면 claude-sonnet-5 또는 claude-haiku-4-5 선택.
이용자는 학회 코드만, 편집위원·편집위원장은 학회 코드 + 역할 코드를 함께 입력해 입장합니다(예: 학회 코드 lis + 편집위원장 코드 lis-ch). 이용자는 원고 처리·자기 학회 결과 열람, 편집위원은 여기에 더해 학회 통계·원고 관리·발행본 비교·채택 요청, 편집위원장은 요청 승인과 자료 삭제까지 가능합니다. 모든 코드는 서로 달라야 하며, 코드를 바꾸면 기존 이용자는 새 코드를 다시 입력해야 합니다.
달러/월 — 비우면 예산 경고 없음
원/달러 환율 — 원화 환산 표시에만 사용
Anthropic API는 잔액 조회를 제공하지 않아, 실제 사용한 토큰을 모델 단가로 환산해 추정합니다. 정확한 청구액은 console.anthropic.com에서 확인하세요.
키는 서버 컴퓨터의 .env에 KCI_API_KEY(KCI 논문), NLK_CERT_KEY(국립중앙도서관 단행본), NANET_API_KEY(국회도서관 학위논문)로 설정합니다. 미설정 시 해당 유형은 '대조 생략' 처리됩니다.

학회 접근 코드
학회에서 안내받은 코드를 입력하면 소속 학회가 자동으로 확인되고, 학회 관련 기능이 열립니다. 편집위원·편집위원장 코드로 입장하면 학회 통계·원고 관리·발행본 비교를 이용할 수 있습니다. 코드가 없다면 소속 학회 편집위원회 또는 관리자에게 문의해 주세요.
소속 학회에서 안내받은 코드입니다.
위 학회 코드와 함께 입력해야 해당 학회의 편집위원·편집위원장으로 확인됩니다.
관리자 로그인
