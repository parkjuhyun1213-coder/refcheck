1. 수집하는 정보

  • 이용자 이름·소속 학회 — 원고 처리 시 입력받아 학회별 이용 통계와 처리 이력 구분에만 사용합니다.
  • 원고 파일(HWP·HWPX·DOCX·PDF·TXT) — 참고문헌 추출·검증을 위해 업로드받습니다. 텍스트 붙여넣기로 제출한 내용은 파일로 저장하지 않습니다.
  • 접근 코드 — 입력한 코드 원문은 저장하지 않고, 일방향 해시(SHA-256)만 브라우저 쿠키(HttpOnly)에 담아 로그인 상태를 유지합니다.
  • 이 외의 개인정보(연락처·이메일·소속 외 정보)는 수집하지 않으며, 광고·추적 스크립트를 쓰지 않습니다.

2. AI(Claude API)로 전송되는 데이터의 정확한 범위

원고 본문은 AI로 전송하지 않습니다. 서비스는 원고에서 참고문헌 구역만 잘라내 그 부분만 AI(Anthropic Claude API)로 보내 문헌 분리·서지 구조화·형식 변환을 수행합니다. 본문 인용 대조(본문–참고문헌 일치 확인)는 서버 안에서만 계산하며 외부로 나가지 않습니다.

  • 예외 — 참고문헌 표제(「참고문헌」·References 등)를 찾지 못했는데 파일 전체가 참고문헌 목록으로 보이는 경우(목록만 담긴 파일 등)에는 파일 전문이 전송되며, 이때 결과 화면에 경고가 표시됩니다.
  • 규정 Q&A — 질문 텍스트와 공개된 투고규정 원문이 전송됩니다. 원고와는 무관합니다.
  • 이용자 이름·소속 학회·파일명은 AI로 전송하지 않습니다.
  • Anthropic은 상용 API 약관상 API로 전송된 입력·출력을 모델 학습에 사용하지 않습니다.

3. 외부 검증 데이터베이스로 전송되는 데이터

참고문헌 실재 검증을 위해 아래 공개 학술 DB에 조회를 보냅니다. 전송되는 것은 모두 "인용된 문헌"의 서지정보(원고가 인용한 논문·도서의 제목·저자 등)이며, 투고자(원고 저자) 이름·이용자 이름·소속 학회는 어떤 외부 DB로도 전송하지 않습니다.

4. 원고의 보관과 열람

  • 업로드된 원고 원본과 처리 결과는 서비스 서버 내부에만 보관합니다. 발행본 대비 검토(투고 원고 → 정리 결과 → 발행본 3자 비교) 등 학회 편집 업무를 위한 보관입니다.
  • 보관된 원고는 소속 학회의 편집위원·편집위원장만 열람할 수 있고, 학회 간에는 서로 볼 수 없습니다.
  • 서버 백업 정책 — 원고 파일은 외부(클라우드·코드 저장소)로 전송하지 않고 같은 서버 안의 백업 폴더에만 복제합니다. 처리 이력(참고문헌 텍스트)은 비공개 저장소에 이중 백업합니다.

5. 파기

  • 수동 편집위원장과 관리자는 보관된 원고(원본·발행본 파일 포함)를 언제든 즉시 삭제할 수 있습니다.
  • 자동 처리 이력이 300건을 넘으면 오래된 것부터 원고 파일을 삭제하고, 통계용 요약(메타정보와 정리된 참고문헌 목록 텍스트)만 남깁니다.
  • 보존 기한 관리자가 원고 보존 기한(일)을 설정하면, 기한이 지난 원고의 원본·발행본 파일이 자동 파기됩니다. 검증 결과와 통계는 유지되며 화면에 "파기됨"으로 표시됩니다. 기한은 학회와 협의해 설정하며, 설정 전에는 무기한 보관(수동 삭제만)입니다.
붙여넣기로 제출한 텍스트는 애초에 파일로 저장되지 않으므로 파기 대상 자체가 없습니다.

6. 보안 조치

  • 원고 처리·결과 열람은 학회 접근 코드가 있어야 하며, 코드는 학회 단위로 발급·회수합니다.
  • 로그인 상태는 HttpOnly 쿠키(스크립트 접근 불가)로만 유지하고, 접속 시도는 IP당 횟수를 제한합니다.
  • AI API 키 등 비밀값은 서버의 환경 파일(.env)에만 두며 코드 저장소·백업에 포함하지 않습니다.
  • 통신은 HTTPS로 암호화됩니다.
